CPRIT — Site du Centre pédagogique régional de l’ICESCO au Tchad

Fichiers:
- index.html : page d'accueil
- styles.css : design responsive
- script.js : menu et langues FR/AR/EN
- assets/logo-cprit.png : logo fourni

Publication simple avec GitHub Pages:
1. Créer un dépôt GitHub, par exemple cprit-icesco-tchad.
2. Téléverser tous les fichiers et le dossier assets en conservant leur structure.
3. Ouvrir Settings > Pages.
4. Choisir Deploy from a branch, branche main, dossier / (root), puis Save.
5. Le site sera publié à l'adresse GitHub Pages indiquée par GitHub.

Avant publication officielle, faire valider par le Centre les textes, les coordonnées, les photos, les programmes et l'usage du logo. Les actualités et formulaires administrables ne sont pas encore connectés à une base de données.
